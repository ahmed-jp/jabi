# JABI Converted Project

صفحة تعريفة لاي شخص قم بتغيير الارقام واسم المشروع .
## الملفات المهمة للتعديل

- `index.html`
- `script.js`
- `manifest.json`

## ما الذي يجب تغييره قبل النشر؟

1. رقم الواتساب التجريبي داخل `index.html` و `script.js`
2. البريد الإلكتروني `hello@jabi.studio`
3. نصوص المشاريع والأسعار إذا كانت مختلفة عن الواقع
4. أيقونة الموقع وبيانات السوشيال إن أردت إضافتها

## التشغيل المحلي

افتح الملف `index.html` مباشرة في المتصفح، أو شغّل أي Live Server من VS Code.

## الملاحظات

- المشروع مبني بـ HTML / CSS / JavaScript فقط.
- لا توجد مكتبات واجهات ثقيلة.
- الواجهة تدعم العربية و RTL.
